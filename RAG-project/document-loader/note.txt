3.1 Arrays and Linked Lists 
Array ek fixed sequence hoti hai jisme elements memory me continuous jagah par store hote hain (Python me list 
is kaam ke liye use hoti hai). Linked List me har element (node) apne agle element ka address (pointer) rakhta 
hai. 
Array 
[10] [20] [30] [40]  — index se direct access (fast) 
Linked List 
[10|next] -> [20|next] -> [30|next] -> None 
class Node: 
    def __init__(self, data): 
        self.data = data 
        self.next = None 
  
class LinkedList: 
    def __init__(self): 
        self.head = None 
  
    def insert(self, data): 
        new_node = Node(data) 
        new_node.next = self.head 
        self.head = new_node 
  
    def display(self): 
        curr = self.head 
        while curr: 
            print(curr.data, end=" -> ") 
            curr = curr.next 
        print("None")

3.4 Binary Search Tree (BST) 
BST ek tree structure hai jisme har node ke left side me usse chhoti values aur right side me badi values hoti hain. 
        8 
      /   \ 
     3     10 
    / \      \ 
   1   6      14 
class Node: 
    def __init__(self, val): 
        self.val = val 
        self.left = None 
        self.right = None 
  
def insert(root, val): 
    if root is None: 
        return Node(val) 
    if val < root.val: 
        root.left = insert(root.left, val) 
    else: 
        root.right = insert(root.right, val) 
    return root 
3.5 Recursion 
Recursion me function khud ko call karta hai jab tak base condition true na ho jaye. 
def factorial(n): 
    if n == 0:              # base case 
        return 1 
    return n * factorial(n - 1)   # recursive call 
  
print(factorial(5))    # 120 
Dhyan rahe: Har recursive function me ek base case zaroor hona chahiye, warna infinite recursion ho jayega 
(RecursionError).

def bubble_sort(arr): 
    n = len(arr) 
    for i in range(n): 
        for j in range(0, n - i - 1): 
            if arr[j] > arr[j + 1]: 
                arr[j], arr[j + 1] = arr[j + 1], arr[j]   # swap 
    return arr 
  
print(bubble_sort([5, 2, 9, 1, 5]))   # [1, 2, 5, 5, 9]

4.3 Decorators 
Decorator ek function hai jo dusre function ko 'wrap' karke uska behaviour badalta hai, bina uska original code

        func() 
        print("Function chalne ke baad")

class Counter: 
    def __init__(self, limit): 
        self.limit = limit 
        self.num = 0 
  
    def __iter__(self): 
        return self 
  
    def __next__(self): 
        if self.num < self.limit: 
            self.num += 1 
            return self.num 
        raise StopIteration 
  
for n in Counter(3): 
    print(n)     # 1 2 3

Methods & Dunder Methods 
Dunder (double underscore) methods jaise __init__, __str__, __len__ Python ki special/magic methods hain jo

class Book: 
    def __init__(self, title, pages): 
        self.title = title 
        self.pages = pages 
  
    def __str__(self):        # print() par ye chalta hai 
        return f"Book: {self.title}" 
  
    def __len__(self):        # len() par ye chalta hai 
        return self.pages 
  
b = Book("Python 101", 300)

6.4 Concurrency 
Concurrency ka matlab hai multiple tasks ko 'ek saath' handle karna (zaroori nahi ki bilkul parallel ho). 
GIL (Global Interpreter Lock) 
GIL Python ka ek lock hai jo ek time par sirf ek thread ko Python bytecode execute karne deta hai — isliye 
CPU-heavy tasks me threading utni fayda nahi deti. 
Threading 
Threading multiple threads (lightweight tasks) chalata hai — I/O-bound kaam (jaise file/network operations) ke 
liye achha hai. 
import threading 
import time 
  
def task(name): 
    print(f"{name} start") 
    time.sleep(2) 
    print(f"{name} done") 
  
t1 = threading.Thread(target=task, args=("Thread-1",)) 
t2 = threading.Thread(target=task, args=("Thread-2",)) 
t1.start() 
t2.start() 
t1.join() 
t2.join() 
Multiprocessing 
Multiprocessing alag-alag processes chalata hai (har process ka apna Python interpreter aur memory hota hai) — 
CPU-heavy tasks ke liye achha hai kyunki GIL ka effect nahi padta. 
from multiprocessing import Process 
  
def square(n): 
    print(n * n) 
  
if __name__ == "__main__": 
    p1 = Process(target=square, args=(5,)) 
    p2 = Process(target=square, args=(10,)) 
    p1.start() 
    p2.start() 
    p1.join() 
    p2.join()
